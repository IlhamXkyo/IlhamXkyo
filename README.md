# Ilham (IlhamXkyo)

Web developer building functional tools, interactive client-side physics engines, and developer utilities.

## Focus Areas

- **Frontend & Web Apps**: Next.js, React, TypeScript, Tailwind CSS, and HTML5 Canvas.
- **Interactive Physics & Graphics**: Three.js, WebGL, Matter.js 2D physics, and procedural Web Audio.
- **Tooling & Automation**: Python, OpenCV, MediaPipe vision pipelines, and local SQLite backends.

## Selected Projects

- [AgentPulse](https://github.com/IlhamXkyo/agent-pulse): Self-hosted AI agent observability and trace waterfall dashboard built with Next.js 15, Prisma, and SQLite.
- [Zero-G Notes](https://github.com/IlhamXkyo/zero-g-notes): Floating desktop sticky note application powered by Electron and Matter.js rigid-body physics.
- [AetherPulse](https://github.com/IlhamXkyo/AetherPulse): Interactive 3D generative particle simulator and WebGL audio visualizer.
- [TrackingHand](https://github.com/IlhamXkyo/TrackingHand): Computer vision hand gesture tracking tool streaming bionic motion capture to Roblox Studio.
- [Aurum AI Terminal](https://github.com/IlhamXkyo/aurum-ai-terminal): Technical market analysis dashboard integrating TradingView charts and multi-step technical pipelines.
